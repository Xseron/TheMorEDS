# Mör

Слой юридической идентичности для Solana: программы, токены и кошельки компаний
подтверждаются государственной электронной подписью. Для eIDAS проверка идёт без
доверенной стороны — подпись удостоверяющего центра над сертификатом проверяет
прекомпайл secp256r1 прямо в транзакции. Для НУЦ РК (ГОСТ 34.10-2015) — через
аттестатор, потому что ГОСТ и Стрибога в Solana нет.

Проект для Colosseum Crypto World's Fair 2026.

## Состояние (неделя 1)

- `programs/mor-registry` — реестр: `TrustService` (УЦ из доверенного списка) и
  `Certificate` (сертификат юридического лица). `register_certificate` проверяет
  подпись УЦ через прекомпайл P-256 и интроспекцию Instructions sysvar, разбирает
  TBSCertificate на месте и сохраняет данные организации.
- `fixtures/` — тестовый УЦ на P-256 и сертификаты для тестов (`gen.sh`).
- `scripts/devnet-v1/` — регистрация сертификата реалистичного размера на devnet
  v1-транзакцией (до 4096 байт).
- Program ID (devnet): см. `Anchor.toml`.

## Сборка и тесты

    anchor build
    cargo test -p mor_registry

## Devnet

    cd scripts/devnet-v1 && npm install && npm run devnet
