Ключи ТОЛЬКО ДЛЯ ТЕСТОВ: тестовый УЦ «Mör Test QTSP» (ca1, ca2) и его тестовые сертификаты (ee, rsa).
Используются в LiteSVM-тестах и в демо на devnet; опубликованы намеренно и ничего не защищают.
`attestor.json` — тестовый Ed25519-ключ аттестатора НУЦ РК (формат keypair Solana), тоже только для тестов и демо.
